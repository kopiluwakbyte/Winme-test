🚀 Cara Deploy ke GitHub Pages:

  1. Buat repository baru di GitHub (misal: winme-chatwoot-test).
  2. Simpan file ini sebagai index.html di root repository.
  3. Buka menu Settings > Pages di repository GitHub Anda.
  4. Di bagian Build and deployment > Source, pilih Deploy from a branch, lalu pilih branch main / root (/) dan klik Save.
  5. Tunggu 1-2 menit hingga link live GitHub Pages Anda aktif (misal: https://username.github.io/winme-chatwoot-test/).
⚠️ Catatan Token & Domain: Pastikan domain GitHub Pages Anda sudah terdaftar atau diizinkan di dashboard Chatwoot Winpay (https://help.winpay.id) jika ada pengaturan restriction domain / CORS pada inbox website token z9g3eZMV5tU41UciEnrEMzGp.
